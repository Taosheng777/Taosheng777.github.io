隐私说明

生效日期：2026-08-24。核心原则很简单：工具输入只在当前页面使用。

本站不会做什么

  • 不要求注册或登录，不设置应用 cookie。
  • 不使用第三方分析、广告、字体、CDN、埋点或远程 API。
  • 不把 Prompt、搜索词、儿童测量值、心理问卷答案、分数、图表或报告上传到服务器。
  • 不使用 Web Storage、IndexedDB 或数据库保存工具输入和结果。

生长发育工具

该工具没有姓名、病历号、联系方式或患者档案字段。性别、月龄、体重、身长/身高和可选头围只用于当前页面即时计算；刷新或关闭页面后不会由本站恢复。请不要把患者身份信息粘贴到任何自由文本区域。

心理测评工具

心理测评工具不提供姓名、联系方式或自由文本字段。只有 Conners 父母症状问卷为按中国常模换算 T 分数提供可选的年龄与性别；不填写时仍可只查看因子均分。年龄、性别、问卷答案和结果都只用于当前页面即时计算，不发送到本站后端、不写入浏览器存储，也不与 GitHub Pages 的托管访问记录关联。

PWA 与离线缓存

为了离线使用，浏览器会缓存 HTML、CSS、JavaScript、图标和内嵌 WHO 标准表。缓存不包含你输入的测量值、搜索词或计算结果。你可以在浏览器的网站设置中清除本站数据，或卸载已安装的 Web App。

托管服务的技术处理

本站自身没有后端和访问日志系统。当前免费公开地址由 GitHub Pages 托管；与任何公开网站一样，GitHub 为传送页面会处理 IP 地址、请求时间、浏览器类型等必要网络信息。本站未接入 GitHub、Cloudflare 或其他第三方分析脚本，也不会把托管层信息与工具输入关联。

适用边界

本说明只适用于当前个人工具网站。未来如建立临床系统，将使用独立仓库、域名和专门隐私规则，不与本站共享患者资料或存储。
