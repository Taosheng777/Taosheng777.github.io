装上

Claude Code

在 Claude Code 里依次输入。三组按需装，不用全装；视频组包含看板、医学科普和通用短片三个入口。更新时输入 /plugin marketplace update taosheng-skills，再到 /plugin 的 Installed 更新已安装的组。

/plugin marketplace add Taosheng777/taosheng-skills
/plugin install taosheng-popsci@taosheng-skills
/plugin install taosheng-work@taosheng-skills
/plugin install taosheng-video@taosheng-skills

Codex

在终端输入，然后在 Codex 的插件目录里选“涛生 Skill”，装你要的那组。

codex plugin marketplace add Taosheng777/taosheng-skills

其他 AI 工具，或者想挑着装

会问你装哪几个、装给哪个 AI。需要电脑上装过 Node.js。

npx skills add Taosheng777/taosheng-skills

human-writing

中文健康科普写作：有具体的人、站得住、不灌水，材料不够就去查或者写短。你可以说：“把这份材料写成给家长看的科普”。

说人话

让 AI 把技术、机制、你自己的配置讲成外行也能拍板的话：先说结果，再打比方，风险讲成后果。你可以说：“说人话”。
