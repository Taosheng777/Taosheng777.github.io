不知道选哪个？先问老爷爷

老爷爷[1]

不知道该怎么问，先找老爷爷。说出你卡在哪里，它会从一组思考方法中挑合适的帮手，继续帮你问清问题、拆方案、做决定。

“老爷爷，我有个想法，但不知道从哪里开始。”

五项常用能力

从科研、表达，到和 AI 一起把事情做完。

01资料科研

学术研究工作流[5]

把选题、写作和审阅连起来。

按研究阶段组织材料、实验规划、论文写作与模拟审稿。适合需要持续推进的科研任务。

你可以这样说“从研究问题到论文结构，帮我梳理下一步。”

获取技能 ↗

02学习表达

说人话[3]

把听不懂的东西，讲到能判断。

把术语、系统和配置讲清楚，先说实际结果，再解释为什么，适合和 AI 对齐理解。

说清楚，才好做决定

“这件事，
对我到底意味着什么？”

先说结果，再解释原因。

你可以这样说“说人话，这个方案对我到底意味着什么？”

获取技能 ↗

03学习表达

Human Writing · 科普写作[3]

把专业材料，写成读者愿意看下去的文章。

从具体读者和真实问题出发，理顺结构、调整措辞，让中文科普自然、清楚、有重点。

修改前本文将围绕相关问题展开系统论述。

修改后先从你最关心的问题说起。

表达示例

你可以这样说“把这份材料写成给家长看的科普。”

获取技能 ↗

04开发协作

Stage Reporting · 阶段汇报[3]

让 AI 把进展讲明白。

做成了什么、还有什么问题、需不需要你决定。每个阶段都能快速掌握实际情况。

一次汇报，讲清三件事

  1. 01结果

    现在已经做成了什么

  2. 02缺口

    还有什么需要解决

  3. 03下一步

    是否需要你决定或操作

你可以这样说“以后每个阶段完成，都先告诉我结果和下一步。”

获取技能 ↗

05资料科研

公众号检索[3]

把公众号里的资料找出来。

按主题搜索微信公众号文章，读取正文并整理为 Markdown，适合发现中文专业资料。

你可以这样说“搜一下公众号里讲这个主题的文章。”

06开发协作

让 AI 少写废代码[2]

先想清楚，再做最小必要修改。

约束 AI 写代码时的常见毛病：不乱加功能、不随手重构，先说明假设，再验证结果。

你可以这样说“只改解决这个问题所必需的部分，并验证改动。”

获取技能 ↗

07思考决策

点子王[1]

开工前，找人认真挑毛病。

从基本事实重新审视方案，找最可能失败的环节，把反对意见变成能执行的改进。

你可以这样说“点子王，帮我拆一下这个方案。”

获取技能 ↗

08开发协作

查 Bug[1]

先复现问题，再找原因。

遇到报错、卡顿或行为异常，沿着证据定位问题，修好后再验证，减少来回碰运气。

你可以这样说“这个功能一直报错，帮我定位原因并验证修复。”

获取技能 ↗

09资料科研

跨平台找资料[4]

需要的内容，不只在普通网页里。

给 AI 补上多平台检索与内容读取能力，用来找社区讨论、视频资料和项目线索。

你可以这样说“帮我找找这个主题在不同平台上的讨论。”

获取技能 ↗

10资料科研

A 股数据取数[6]

让分析先有真实数据。

提供行情、财务和市场资料的取数路径与备用来源。用于研究准备，不执行交易。

你可以这样说“获取这只股票的真实行情，标清来源和日期。”

获取技能 ↗

11思考决策

专家会诊[1]

让不同专业的人互相质疑。

一个问题横跨多个领域时，组合互补视角，比较分歧，再给出条件明确的建议。

你可以这样说“从三个互补专业视角看看这个方案。”

获取技能 ↗

12资料科研

事实核查[1]

把“听着有道理”变成有据可查。

区分事实、推论与观点，寻找可追溯来源，指出证据不够或推理跳步的地方。

你可以这样说“帮我查证这个说法，区分事实和推测。”

获取技能 ↗

13思考决策

最小实验[1]

别一直纠结，先小成本试一次。

把不确定的想法变成可逆的小实验，说明要验证什么、怎么做、怎样判断成败。

你可以这样说“帮我设计一个七天能完成的小实验。”

把选中的能力装到电脑

最省事：把安装提示词交给 AI

单个技能用上方卡片的复制按钮。想安装涛生公开合集，就复制下面这段，粘贴给电脑上的 Claude Code 或 Codex。

完整版 v2.0.0 包含 102 个技能入口，老爷爷和配套思考方法也已打包。这里展示我常用的几项，完整清单见仓库。

请帮我安装涛生 Skill：https://github.com/Taosheng777/taosheng-skills。先阅读 README，安装 taosheng-environment 完整版，确认老爷爷和配套方法都已安装；按我当前的 AI 工具运行安装检查，保留已有配置，最后说明还需补齐哪些工具或账号。

复制只会把文字放进剪贴板；安装在你自己的 AI 工具中完成。需要的账号、依赖和权限以各仓库说明为准。

习惯用命令行？展开安装方式

Claude Code

先添加市场，再安装完整版。已经添加过的市场，先更新后再安装。

/plugin marketplace add Taosheng777/taosheng-skills
/plugin install taosheng-environment@taosheng-skills

Codex

添加市场后安装“涛生完整技能环境”；已有市场先执行 codex plugin marketplace upgrade taosheng-skills。只添加市场不会自动安装技能。

codex plugin marketplace add Taosheng777/taosheng-skills
codex plugin add taosheng-environment@taosheng-skills

其他 AI 工具，或挑选单个技能

需要 Node.js；按提示选择技能及目标 AI 工具。

npx skills add Taosheng777/taosheng-skills --skill '*'
